# V1.4 Implementation Plan

This file records the implementation sequence before modifying the runtime code.

1. Reuse the existing validated image-generation backend instead of duplicating provider logic.
2. Add helpers to generate a master image from persisted `metadata.master_prompt` and to generate keyframes from the persisted master plus per-plan `keyframe_prompt`.
3. Persist each generated image immediately into Production State.
4. Extend the orchestrator so image preparation runs before Veo submission.
5. Preserve V1.3 retry/fallback/montage behavior unchanged downstream.
6. Extend the OpenAPI description/version while keeping the existing `advanceFalcoProduction` operation stable.
7. Validate syntax and production-state transitions before deployment.

The runtime must not invent missing prompts. Missing master or keyframe prompts produce explicit waiting states.
